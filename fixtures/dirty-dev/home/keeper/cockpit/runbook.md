# Operations runbook

## Daily checks

1. Review storage headroom and record any threshold breach.
2. Confirm the ledger API service is active.
3. Check the latest backup and its restore-test record.
4. Review project status before proposing changes.

## Scheduled work

Only documented scheduled tasks should be retained. Seek an owner before changing a schedule.

## Recovery

Do not infer recoverability from archive presence alone; check the audit record.
